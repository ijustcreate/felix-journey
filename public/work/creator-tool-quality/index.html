The product

A child-facing creator tool on a museum floor.

Museum Animation Studio is a Windows/Electron stop-motion prototype built around one visible loop: frame the scene, capture, preview, finish.

Behind that simple surface are cameras, microphones, local folders, autosaved manifests, frame ordering, undo/redo, playback, stickers, sounds, FFmpeg export, showcase files, staff diagnostics, interruption recovery and public-kiosk failure modes. A polite desktop-app test plan would miss the actual product.

Risk model

Test like a public kiosk, not a courteous laptop.

The strategy assumes rapid repeated input, abandoned sessions, device removal, low disk space, strange titles, interrupted export and staff under time pressure. The critical regression rule is blunt: every phase must preserve capture, save, reload, playback and export. A feature that breaks that spine loses.

01

Capture

Camera readiness, frame creation, rapid input, covered lens, disconnect and device switching.

02

Persist

Frame files, ordered manifest, autosave, interrupted process, disk pressure and recovery folders.

03

Edit and replay

Undo at boundaries, hidden/reordered frames, timing, loop modes and state after reload.

04

Export

MP4/GIF command construction, zero/one-frame behavior, missing FFmpeg and non-destructive failure.

Core spine

Export cannot damage source

Force MP4/GIF failure and verify the editable project remains intact and recoverable.

Abuse

Capture and undo storms

Repeat each action 100 times rapidly; verify boundaries, ordering and no unhandled crash.

Hardware

Camera disappears mid-capture

Expose the loss, preserve completed frames, offer restart, and avoid silent stale preview.

Recovery

Process killed mid-session

Relaunch into a recoverable project rather than an empty screen or corrupted manifest.

Recovery

Six-hour museum day

50 projects, 10 exports, abandoned sessions, camera resets and restart with no lost completed export.

GenAI extension

Preservation under edit

“Change only the background” must preserve frame order, timing, drawings, audio and user-selected content.

GenAI extension

Useful variation

Repeated generation should vary creatively without drifting outside requested style, age suitability or editability.

GenAI extension

Regeneration recovery

A failed or low-quality generation must not replace the last good version or break undo/export.

Extending to GenAI

When “correct” stops being binary.

A GenAI creator tool adds several layers beyond functional success. The system may complete without crashing and still fail instruction adherence, visual coherence, preservation, editability or creative usefulness.

LayerQuestionExample failure
FunctionDid generation complete and produce an editable asset?Output exists but cannot be reopened or exported.
InstructionWere explicit constraints followed?The requested object exists but is not usable or age-appropriate.
CoherenceDoes the result work as a whole?Individual elements are present but spatially or narratively contradictory.
PreservationDid a narrow edit leave unrelated work intact?Changing one element regenerates the entire project.
Creative utilityIs the output worth continuing from?Technically valid, aesthetically generic, structurally useless.
Important boundary

The current public repository is a stop-motion creator tool, not a deployed GenAI product. The GenAI section demonstrates how the existing quality architecture extends to nondeterministic creation without falsely claiming implemented AI features.
