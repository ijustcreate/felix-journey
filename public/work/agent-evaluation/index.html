The evaluation problem

“Helpful” is not a sufficient acceptance criterion.

An agent can produce a polished answer while choosing the wrong tool, carrying unsafe data, inventing facts, crossing an authorization boundary, or claiming an action succeeded when it did not.

Application Companion deliberately limits its scope: it prepares a fact-conscious prompt, opens a safe employer page, and leaves review and submission to the applicant. It does not collect credentials, store résumé contents, authenticate into employer systems, autofill, or submit. That makes it a useful public substrate for demonstrating agent evaluation without pretending a static prototype is an autonomous production agent.

Evidence and boundary

Implemented controls, not decorative ethics wallpaper.

The public code normalizes saved state through a strict allowlist, rejects non-HTTPS links and URLs with embedded credentials, strips unknown fields from import/export, and generates a prompt that prohibits invented credentials and secrets. Automated tests exercise those boundaries.
